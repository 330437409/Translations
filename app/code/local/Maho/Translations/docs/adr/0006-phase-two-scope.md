# ADR-0006：二期范围调整，内联编辑推迟到第三期

## 状态

已接受。剩余二期/三期排期已被 [ADR-0009](0009-pause-roadmap.md) 暂停。

## 背景

ADR-0005 把 AI 辅助、内联编辑、内容翻译和超长文案都放到第二期。第一期交付后重新评估，内联编辑需要改前台渲染链路、权限、AJAX 和大量页面回归，风险和工作量明显高于其余三项。

第二期需要先交付可独立验证的翻译能力，内联编辑不应阻塞二期。

## 决策

第二期只做 FR-10、FR-12、FR-13：AI 辅助翻译、内容翻译和超长文案支持。

FR-11 内联编辑推迟到第三期，与 FR-14 审计回滚及后续规模化能力一起规划。

## 理由

- 内联编辑改动渲染输出，回归面最大，需要单独的验收和回滚方案。
- AI 辅助、内容翻译和超长文案都能复用现有的索引、`core_translate` 和 CSV 能力，交付风险更低。
- 三期前不做内联编辑，可以避免二期范围再次失控。

## 后果

- PRD 的 FR-11 优先级从 P2 调整为 P3。
- ADR-0005 中“内联编辑放到第二期”的排期部分由本 ADR 取代；ADR-0005 的第一期范围决策继续有效。
- 第三期范围包含 FR-11、FR-14，以及翻译记忆、术语表等规模化能力。
- 本次调整不改变现有代码和 0.1.1 的行为。

## 备选方案

- **保留内联编辑在第二期**：回归面大，会阻塞 AI 和内容翻译，不采用。
- **彻底取消内联编辑**：仍有后台编辑需求，只是不在三期前做，不采用。
- **先做内联编辑**：需要先改渲染链路，风险最高，不采用。
