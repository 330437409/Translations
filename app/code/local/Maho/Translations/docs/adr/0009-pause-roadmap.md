# ADR-0009：暂停剩余二期和三期功能计划

## 状态

已接受。

## 背景

0.3.0 已交付扫描索引、翻译网格、编辑与清除、CSV 导入导出、占位符校验、AI 翻译草稿和超长文案。剩余需求包括 FR-12 内容翻译、FR-11 内联编辑、FR-14 审计回滚，以及翻译记忆和术语表。

这些能力会扩大回归面、数据模型和运维成本。当前功能已经覆盖日常界面文案管理，继续开发的优先级下降。

## 决策

把 0.3.0 作为当前功能基线。剩余二期和三期功能暂停，不排期，不删除需求。

恢复任何暂停项之前，先重新确认范围、验收和排期，并新增或取代 ADR。维护、bug 修复和安全修复不暂停。

## 理由

- 当前功能已覆盖扫描、编辑、CSV、AI 草稿和长文案。
- 内联编辑会改渲染链路，审计回滚会增加长期数据，继续开发的收益低于维护成本。
- 暂停比删除更容易在未来恢复，也保留 PRD 和 ADR 的历史。

## 后果

- PRD 的 FR-11、FR-12、FR-14 标为“暂停”。
- ADR-0006 中剩余二期/三期排期被本 ADR 暂停；第一期和第二期已完成的范围继续有效。
- 不新增功能代码，只做维护、修复和安全更新。
- 翻译记忆和术语表仍保留为未登记方向，不进入当前计划。

## 备选方案

- **继续按原计划开发**：回归和运维成本高，当前收益不足，不采用。
- **永久删除剩余需求**：未来可能仍需内容翻译或内联编辑，不采用。
- **只保留维护分支**：暂停已经覆盖这一点，不额外建立分支，不采用。
