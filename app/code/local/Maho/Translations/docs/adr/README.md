# 架构决策记录（ADR）

本目录记录 `Maho_Translations` 模块的重大架构决策。编号从 0001 开始，文件名使用英文 slug，正文使用中文。

| 编号 | 标题 | 状态 |
|---|---|---|
| 0001 | 使用 `core_translate` 作为唯一写入目标，不重写 `core/translate` | 已接受 |
| 0002 | 使用扫描索引表和声明式 schema | 已接受 |
| 0003 | 占位符校验失败时阻止保存和导入 | 已接受 |
| 0004 | 超过 255 字符的文案第一期只读 | 已被 ADR-0008 取代 |
| 0005 | 第一期不做 AI、内联编辑和内容翻译 | 已接受（二期排期部分被 0006 取代） |
| 0006 | 二期范围调整，内联编辑推迟到第三期 | 已接受（剩余排期被 0009 暂停） |
| 0007 | AI 翻译只生成草稿，人工审核后写入 core_translate | 已接受 |
| 0008 | 超长文案使用独立表并通过 core/translate 资源合并 | 已接受 |
| 0009 | 暂停剩余二期和三期功能计划 | 已接受 |

新增 ADR 时复制 `_template.md`，顺序编号。已被取代的 ADR 不删除，状态改为“已被 ADR-NNNN 取代”。
