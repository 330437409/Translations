# 范围纪律

第一期范围（已交付）是 PRD 中 FR-01 到 FR-09：

- 扫描与索引
- 翻译网格
- 编辑与清除覆盖
- 占位符校验
- CSV 导出
- CSV 导入
- 缺失/未使用视图
- 菜单与权限
- CLI 扫描

FR-10 AI 辅助翻译已交付@0.2.0，边界以 `docs/specs/ai-translation.md` 和 ADR-0007 为准。FR-13 超长文案已交付@0.3.0，边界以 `docs/specs/long-translations.md` 和 ADR-0008 为准。0.3.0 是当前功能基线；FR-12、FR-11、FR-14 和翻译记忆/术语表已由 ADR-0009 暂停，不新增功能代码，只做维护和修复。

第一期历史边界（不代表第二期）：

- AI 辅助翻译
- 内联编辑
- 商品、分类、CMS 内容翻译
- 超长文案编辑
- 主题 `translate.csv`
- `jstranslator.xml`
- 审计日志和回滚
- 公开 API

遇到“顺手加一个”的冲动时先记录到 PRD 的后续期，不改当前期范围。确实需要提前做时，先让用户确认并更新 PRD、spec 和 ADR。

不做占位字段、不做未使用的配置项、不为后续期能力预埋空实现。
